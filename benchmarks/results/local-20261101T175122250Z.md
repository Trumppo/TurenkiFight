## Network fields

All network fields are `NOT_MEASURED`: latency, jitter, packet loss, join success, TURN cost and bandwidth. `measuredNetworks` is `0`. No LAN, internet, browser or TURN run occurred.

## What these numbers do not mean

- They are not network latency, jitter, loss, join reliability or TURN cost.
- They are not browser frame pacing, rendering cost or device performance.
- Codec bytes are canonical JSON UTF-8 bytes; transport framing (WebSocket or WebRTC) is not included.
- Durations vary by machine, load and Node version. Only the byte counts are deterministic.
- A single local run cannot choose between WebSocket and WebRTC.

## Reproduce

```sh
npm ci
npm run measure:local
```

The default writes a new `benchmarks/results/local-<UTC timestamp>.json` and `.md`. Raw samples are not embedded; this command is the regeneration path.
