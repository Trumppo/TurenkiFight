## What these numbers do not mean

- They are not network latency, jitter, packet loss, join success, TURN cost or bandwidth. All network fields are `NOT_MEASURED`; `measuredNetworks` is `0`.
- They are not a WebSocket-vs-WebRTC comparison and select no transport.
- They are not browser frame pacing, rendering cost or device performance.
- Codec bytes are canonical JSON UTF-8 bytes; WebSocket frame headers and TCP/IP overhead are not included.
- Manual-pacing tick and codec durations are deterministic-workload facts, not real-time pacing. The interval server cost run is real-time, but its per-tick latency is not instrumented.
- Timing, CPU and RSS vary with machine, background load and Node version. Only byte counts are deterministic.
- One machine and one run are not a capacity guarantee.
