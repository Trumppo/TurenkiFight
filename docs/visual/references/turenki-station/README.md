# Turenki Railway Station Reference Photos (2026-11-11)

## Source
Multiple high-quality photos provided by the project owner from different angles and seasons:
- Frontal view with canopy and "TURENKI" sign
- Side and platform views
- Winter (snow) and summer/daylight versions

These are the authoritative real-world references for color (nearly white / light pinkish-white wooden siding, dark grey roof, white trim) and proportions.

## Files
Original photos are stored as conversation attachments in the development discussion dated 2026-11-11.
For permanent storage copy the clearest images here and name them descriptively.

## Key Observations for Retro Conversion
- Facade: nearly white or slightly pinkish-white horizontal siding
- Roof: dark grey / slate
- Trim, frames, columns: crisp white
- Canopy: prominent with "TURENKI" sign
- Platform must remain very quiet in the final art
